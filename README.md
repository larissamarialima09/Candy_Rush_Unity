# Candy Rush

Projeto de jogo desenvolvido em Unity.

## Abrir e executar

1. Instale o Unity Editor **6000.6.2f1** pelo Unity Hub.
2. No Unity Hub, adicione a pasta que contem `Assets`, `Packages` e `ProjectSettings`.
3. Abra o projeto e aguarde a importacao dos assets e a instalacao dos pacotes.
4. Abra `Assets/Scenes/Main.unity` e pressione **Play**.

As cenas habilitadas para o build sao `Main` e `CandyRush`.

## Estrutura

- `Assets/`: scripts, cenas, imagens e demais recursos do jogo, com seus arquivos `.meta`.
- `Packages/`: dependencias do projeto.
- `ProjectSettings/`: configuracoes da Unity.
- `Tools/`: ferramentas auxiliares de desenvolvimento.

Os caches da Unity, builds e arquivos temporarios sao ignorados pelo Git e gerados novamente quando necessario.
